Debt Freedom — privacy-safe hostable app

IMPORTANT:
This folder contains NO personal debt balances.
It is safe to use as the public GitHub Pages source.

Do NOT upload my_debt_freedom_plan.json to GitHub.
That separate file contains your personal plan and should stay on your phone.

After the site is installed/opened:
1. Go to Home.
2. Select my_debt_freedom_plan.json.
3. The plan imports and is stored locally on the device.

Use Export backup from the app regularly.
